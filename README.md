

## Project Overview
CourseHunt is an open-source platform for discovering and managing online programming and data science courses.

### Key Features
- Interactive course catalog with real-time search
- Category filters and difficulty tags
- Curriculum preview with unit accordions

### Built With
- React 18
- React Router v6
- Tailwind CSS & PostCSS

### Local Development Setup
```bash
git clone https://github.com/harshitnub077/CourseHunt.git
cd CourseHunt
npm install
npm start
```
